operational_rules:

  trading_rules:

    - rule: "Use conceptual frameworks over isolated indicators."
      checklist:
        - What structural mechanism explains this?
        - What regime assumptions exist?
        - What cross-domain analogy applies?
        - Is this transferable across markets?

    - rule: "Fermi-ize complex market questions."
      implementation:
        - Break macro problems into components.
        - Estimate probabilities incrementally.
        - Use rough-order reasoning before precision.

    - rule: "Build transferable market abstractions."
      implementation:
        - Focus on:
            - liquidity
            - incentives
            - reflexivity
            - volatility
            - positioning
            - behavior

    - rule: "Avoid narrow local optimization."
      checklist:
        - Does this improve only recent backtests?
        - Is robustness sacrificed?
        - Is this regime-dependent?

  machine_learning_rules:

    - rule: "Optimize for transferable representations."
      checklist:
        - Does model generalize?
        - Is this abstraction or memorization?
        - Does feature structure survive regime shifts?

    - rule: "Think computationally."
      implementation:
        - Decompose large problems.
        - Create modular systems.
        - Use abstraction layers.
        - Separate signal from representation.

  learning_rules:

    - rule: "Prioritize reusable reasoning tools."
      checklist:
        - Can this apply elsewhere?
        - Is this principle invariant?
        - Does this improve reasoning quality?

    - rule: "Study outside primary domain."
      implementation:
        - Read across:
            - biology
            - economics
            - psychology
            - complexity science
            - AI
            - systems theory

    - rule: "Build conceptual scaffolding."
      implementation:
        - Maintain interconnected knowledge graph.
        - Link ideas via abstractions.
        - Track cross-domain analogies.
